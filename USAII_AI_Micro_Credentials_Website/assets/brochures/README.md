# Course brochures

Put the brochure PDFs here, one per course, named after the course page address:

- `ai-fluency-for-the-workplace.pdf`
- `prompting-and-context-design.pdf`
- `agentic-ai-foundations.pdf`
- `rag-and-enterprise-knowledge-assistants.pdf`
- `ai-for-data-analysis-excel-and-bi.pdf`
- `ai-for-project-management.pdf`
- `ai-for-hr-recruiting-and-workforce-planning.pdf`
- `ai-for-marketing-and-content-creation.pdf`

To replace a brochure, upload the new file with the same name. To use another file name, set it in
`assets/js/config.js` (`brochures`). To show the Download Brochure form on the home page, set
`brochureForm: true` in `assets/js/config.js`.
