What you’ll learn

From asking AI to having it do the job

  • Spot a Real Agent Job

    Tell an agent from a chatbot by four markers: a goal, tools, several steps and a trigger.

  • Pick One Bounded Job

    Choose work with a clear trigger, a clear finish and clear edges.

  • Grant Minimum Access

    Give each tool the lowest permission that works: read, draft, write or send.

  • Keep a Human in the Loop

    Set approval gates, handoffs and stop rules, each with a named person.

  • Build Without Code

    Wire the trigger, tools, task flow and a review point in a no code tool.

  • Road Test Before You Rely

    Run normal, failure and stop rule cases, fix what breaks and state the limits.

Who it’s for

Operations and admin staff, coordinators, team leads, analysts and anyone exploring how AI agents could take on part of a team’s workload.

What you need

A computer, a web browser, a no code automation or agent building tool (a free trial with test data works) and one recurring, multistep job with a clear trigger and finish.

Learning Outcomes

You will be able to identify and evaluate agent opportunities, define bounded agent jobs, map goals, tasks, tools, memory, permissions, and human approval controls, and complete an Agent Design Canvas. They will also build a working agent using an approved no code tool, configure its workflows and review points, and identify potential risks, failure points, and corresponding safeguards.

Frequently asked questions

Do I need to code?

No. You build the agent in a no code tool.

Which tool do I need?

A no code automation or agent building tool your organization approves. Without one, use a free or trial workspace with test data only.

Will my agent touch live systems?

No. You build and test in a test workspace on sample or sanitized data. Nothing connects to anything that can spend money, change important records or contact people without your review.

How long does it take?

About 10 hours: ten one hour sessions. Finish in two weeks of business days or set your own pace.

Is there a live instructor?

No. The course is fully self paced. The USAII® Intuitive LMS tracks your progress and points you to your next best step.

What if my agent doesn’t pass review?

You get specific feedback and one round to revise and resubmit.

Is this a USAII® certification?

It’s an applied Certificate of Completion, separate from USAII®’s proctored certifications and an on ramp to them.
